# نشر مسابقة توقعات كأس العالم 2026 (Netlify + Supabase)

هذا المشروع جاهز للبناء والنشر. تحتاج حسابين مجانيين: Supabase (قاعدة البيانات)
و Netlify (الاستضافة). اتبع الخطوات بالترتيب.

محتويات المجلد:
- src/App.jsx          ← التطبيق (يقرأ مفاتيح Supabase من متغيرات البيئة)
- src/main.jsx         ← نقطة التشغيل
- index.html           ← الصفحة + Tailwind + الخط العربي
- package.json         ← الاعتماديات وأوامر البناء
- vite.config.js       ← إعداد Vite
- netlify.toml         ← إعداد النشر
- supabase-schema.sql  ← جداول قاعدة البيانات
- .env.example         ← نموذج المفاتيح

═══════════════════════════════════
الخطوة 1 — قاعدة البيانات (Supabase)
═══════════════════════════════════
1. ادخل https://supabase.com وأنشئ حسابًا ثم مشروعًا جديدًا (مجاني).
2. انتظر دقيقة حتى يجهز المشروع.
3. من القائمة الجانبية: SQL Editor → New query.
4. الصق محتوى ملف supabase-schema.sql كاملًا ثم اضغط Run.
   تُنشأ 3 جداول: predictions / results / matches.
5. من Project Settings → API انسخ قيمتين:
   - Project URL  (مثل https://abcd.supabase.co)
   - anon public key (نص طويل يبدأ بـ eyJ...)

═══════════════════════════════════
الخطوة 2 — جرّب محليًا (اختياري لكن مفيد)
═══════════════════════════════════
1. ثبّت Node.js من https://nodejs.org إن لم يكن موجودًا.
2. داخل مجلد المشروع نفّذ:

       npm install

3. انسخ .env.example إلى .env واملأ القيمتين من الخطوة 1.
4. شغّل:

       npm run dev

   افتح الرابط الظاهر وجرّب. لإيقافه: Ctrl + C.

═══════════════════════════════════
الخطوة 3 — النشر على Netlify (عبر GitHub — مُوصى به)
═══════════════════════════════════
1. ارفع مجلد المشروع إلى مستودع GitHub جديد (private أو public).
2. ادخل https://app.netlify.com → Add new site → Import an existing project.
3. اختر مستودع GitHub. الإعدادات تُقرأ تلقائيًا من netlify.toml:
   - Build command: npm run build
   - Publish directory: dist
4. قبل الضغط على Deploy: افتح Site configuration → Environment variables
   وأضف متغيّرين:
   - VITE_SUPABASE_URL       = (Project URL من Supabase)
   - VITE_SUPABASE_ANON_KEY  = (anon public key)
5. اضغط Deploy. خلال دقيقة يصبح لديك رابط عام مثل your-app.netlify.app
6. وزّع الرابط على المشاركين — كلٌّ يدخل باسمه فقط.

— طريقة بديلة سريعة (سحب وإفلات) —
نفّذ npm run build ثم اسحب مجلد dist إلى app.netlify.com.
لكن هذه الطريقة لا تقرأ متغيرات البيئة، فاستخدم طريقة GitHub للمشاركة الحقيقية.

═══════════════════════════════════
الخطوة 4 — أنت الأدمن
═══════════════════════════════════
- ادخل التطبيق المنشور → القائمة الرئيسية → الإدارة → الرمز 2026
  (غيّره من ثابت ADMIN_CODE في src/App.jsx قبل النشر).
- ترى توقعات الجميع (حتى المخفية عن المشاركين)، وتصدّر التقارير،
  وتُدخل نتائج المباريات والنتائج الفعلية فتُحسب نقاط الجميع تلقائيًا.
